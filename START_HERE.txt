BEFORE YOU START
----------------
1. Get Alpaca paper keys (free): https://app.alpaca.markets/paper/dashboard/overview
2. You will paste them in the browser in Step 3 (we never see them).


STEP 1 – RUN SETUP (one time)
-----------------------------
  Mac/Linux:  Open Terminal, go to this folder, then run:
    chmod +x setup.sh start_dashboard.sh
    ./setup.sh

  Windows:  Open Command Prompt, go to this folder, then run:
    python setup.py


STEP 2 – START THE DASHBOARD
-----------------------------
  Mac/Linux:  ./start_dashboard.sh
  Windows:    python dashboard\command_center.py

  Leave that window open. You should see: "Open in your browser: http://localhost:8083"


STEP 3 – OPEN YOUR BROWSER
-----------------------------
  Go to:  http://localhost:8083

  On the setup page, paste your Alpaca API Key and Secret, then click
  "Save and test connection." When it says "Connection successful," you're done.
